# End-to-End CI/CD Pipeline Using Jenkins, Docker and Kubernetes

## Project Overview

This project demonstrates a complete CI/CD pipeline using GitHub, Jenkins, Docker and Kubernetes.

## Tools Used

- Linux
- Git
- GitHub
- Jenkins
- Docker
- Docker Hub
- Kubernetes

## Workflow

1. Developer pushes code to GitHub
2. Jenkins automatically triggers build
3. Docker image is created
4. Docker image is pushed to Docker Hub
5. Kubernetes deploys latest image
6. Application becomes available to users

## Benefits

- Automated deployment
- Faster release process
- Reduced manual effort
- Consistent deployments
